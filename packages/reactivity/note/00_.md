#### ref
proxy 无法用于原始值
通过 ref 类将原始值包装为对象
通过类方法模拟 proxy 来拦截值的获取与设置
获取值时通过类内的 dep 对象与订阅者建立联系
修改值时通过 dep 对象通知订阅者

##### shallowRef
不会进一步将 value 值转变为响应式

#### reactive
通过 proxy 将普通对象转变为响应式对象
在 proxy 回调中拦截对象操作
获取属性值时在回调中创建 dep 对象并建立订阅关系
设置属性值时在回调中通过 dep 对象通知订阅者

##### receiver
Reflect.get 遇到 getter 或方法调用时，自动将 receiver 作为 this 传递
receiver 确保在访问器属性和方法中 this 指向正确的对象，指向最初的调用者而不是中间的对象

响应式对象内存在访问器时，让访问器中的 this 指向响应式对象，而不是原始对象
