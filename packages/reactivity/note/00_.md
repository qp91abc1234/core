#### reactive
代理 + 订阅发布者
通过 proxy 拦截对象操作
获取属性值时
    在回调中创建一一对应发布者对象
    与当前激活的订阅者建立订阅关系
        订阅关系存储于 link 节点中
        订阅者与发布者通过双向链表引用 link 节点
设置属性值时
    在回调中通过 dep 对象内的订阅关系链表通知订阅者

##### receiver
Reflect.get 遇到 getter 或方法调用时，自动将 receiver 作为 this 传递
receiver 确保在访问器属性和方法中 this 指向正确的对象，指向最初的调用者而不是中间的对象

```
const zc = reactive({
  a: 1,
  tst() {
    this.a + 1
  }
})
zc.tst() // this === zc
```

##### shallow
浅响应，不会进一步对属性值进行转换，减少不必要的响应式追踪
适用于整体替换而非局部更新的场景
主要应用于性能优化场景使用

#### ref
proxy 无法用于原始值
通过 ref 将原始值包装为对象
通过类方法模拟 proxy 回调来拦截值的操作
获取值时通过类内的 dep 对象与订阅者建立联系
修改值时通过 dep 对象通知订阅者

#### 计算属性
即是发布者也是订阅者
第一次获取值时
    发布者与外部订阅者建立订阅关系
    执行计算函数，计算函数内部的响应式变量与订阅者建立订阅关系
    返回计算属性值
计算函数内响应式变量变更
    通知订阅者，将计算属性标记为 dirty
    通知外部订阅者
    重新获取值，重新计算
